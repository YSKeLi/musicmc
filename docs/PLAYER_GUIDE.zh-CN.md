# 玩家使用教程

[English](PLAYER_GUIDE.md) | [简体中文](PLAYER_GUIDE.zh-CN.md)

## 浏览歌曲和获取唱片

- `/music`：打开歌曲菜单。菜单包含全部歌曲、最近上传、我的投稿、搜索、翻页和待提交凭证数量。
- `/music browse`：明确打开同一个歌曲菜单。
- `/music search <关键词>`：按歌曲、歌手、命令名称或上传者搜索并打开菜单。
- `/music list [页码]`：在聊天栏查看分页歌曲列表。
- `/getcd <命令名称>`：获得指定唱片，并且只请求这首歌所在的资源包。输入命令时会自动补全可选名称。
- `/music pack`：移除并重新请求当前全部 MusicMC 资源包。资源包加载失败或曾被拒绝时使用。
- `/music cancel`：清除自己本地签发且尚未过期的凭证，不会取消已经运行的 GitHub 任务。

把 MusicMC 唱片放入唱片机前，请先接受资源包。音乐只能在唱片机周围 25 格内听到，并随距离线性减弱。播放开始后才进入范围的玩家，会先加载对应资源包，然后从下一个约 5 秒的片段加入同步播放。

## 提交 ZIP 音乐

1. 执行 `/music upload <命令名称>`。例如使用 `/music upload abc`，不要写成 `/music upload abc.mp3`；以后玩家通过 `/getcd abc` 获取唱片。
2. 点击聊天栏中的签名投稿链接。
3. 选择一个只包含 1 个受支持音频文件的 ZIP。
4. 点击提交，等待 GitHub 自动处理。
5. 可用 `/music status` 和网页提供的任务链接查看状态。目录下一次同步后，歌曲会出现在菜单和 `/getcd` 自动补全中。

ZIP 压缩包名称现在不需要和歌曲名称相同，MusicMC 会自动生成安全的内部文件名。支持 MP3、M4A、AAC、WAV、FLAC、OGG、OPUS；ZIP 最大 25 MB，解压后音频最大 100 MB，时长不超过 10 分钟。

## 提交网易云歌曲

1. 如果已经知道数字歌曲 ID，执行 `/music netease <ID>`，例如 `/music netease 254132`。
2. 如果手上是完整链接，执行 `/music netease url <网易云歌曲链接>`，例如 `/music netease url https://music.163.com/song?id=254132`。
3. 打开签名链接。网页会通过签名保护的查询接口自动显示网易云歌曲 ID、歌曲标题、歌手，以及自动生成的唱片命令名称。
4. 确认信息后提交，不需要从本地上传 ZIP。发布后可使用网页显示的 `/getcd <唱片命令名称>` 获取唱片。

歌曲信息查询不会把网易云 Cookie 发送到网页；Cookie 只供 GitHub Actions 获取音频。只有管理员配置了 `NETEASE_COOKIE` 时音频处理才可用。任务失败时 Issue 会显示更具体的原因，例如 Cookie 过期、账号不能播放、网易云风控或下载地址异常。旧任务关闭后可以重新创建投稿。
如果失败的 Issue 已关闭，但插件仍显示旧本地凭证，先执行 `/music cancel` 再重试。

## 投稿队列规则

每名玩家的历史投稿总次数没有限制，但同一时间只能有 1 个正在处理的任务；重复的命令名称不能提交。

## 状态命令

`/music status` 会显示歌曲目录是否正在同步、服务器能否签发投稿凭证，以及你本地生成且尚未过期的凭证。GitHub Issues 才是实际处理队列的权威状态。
