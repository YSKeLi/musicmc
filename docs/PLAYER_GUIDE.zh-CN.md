# MusicMC 玩家使用教程

## 上传歌曲

假设歌曲名称是 `abc`：

1. 在服务器聊天栏执行：

   ```text
   /music upload abc
   ```

   命令中的歌曲名称不要写 `.mp3`、`.flac` 等扩展名。

2. 点击服务器返回的上传链接。
3. 准备名为 `abc.zip` 的压缩包。ZIP 名称必须与命令中的歌曲名称完全一致。
4. ZIP 内必须且只能有一个音乐文件，可以是 MP3、M4A、AAC、WAV、FLAC、OGG 或 OPUS。
5. 在上传页面选择文件时，确保光标和文件选择区域位于 **音乐 ZIP 文件** 的下方。
6. 选择 `abc.zip`，然后点击 **上传并提交**。
7. 页面显示提交成功后等待服务器处理。服务器默认每 120 秒同步一次目录。
8. 发布完成后执行：

   ```text
   /getcd abc
   ```

## 文件限制

- ZIP 最大 25 MB。
- 解压后只能有一个受支持的音频文件。
- 歌曲最长 10 分钟。
- 不支持加密 ZIP。
- 歌曲名称必须是 1 到 48 个字符。
- 上传链接默认 15 分钟后过期；过期后重新执行 `/music upload <名称>`。

## 所有命令

| 命令 | 作用 |
| --- | --- |
| `/music upload <名称>` | 创建该歌曲的一次性上传链接 |
| `/music list` | 查看第一页歌曲 |
| `/music list <页码>` | 查看指定页歌曲 |
| `/music status` | 查看目录同步状态和自己的待处理上传 |
| `/music pack` | 重新下载当前所有歌曲资源包 |
| `/music sync` | 管理员立即同步 GitHub 歌曲目录 |
| `/getcd <名称>` | 获取指定歌曲唱片；输入时会自动提示歌曲名称 |

## 播放范围

唱片放入唱片机后，默认只有 25 格范围内的玩家可以听到。声音随距离线性降低，越远越小，到 25 格时静音。

## 常见问题

### 页面提示链接无效

返回服务器重新执行 `/music upload <名称>`，使用新生成的完整链接。

### 页面提示压缩包名称不正确

命令是 `/music upload abc` 时，压缩包必须叫 `abc.zip`，不能叫 `abc.mp3.zip` 或其他名称。

### 已经发布但 `/getcd` 找不到

等待下一次自动同步，或请管理员执行 `/music sync`。命令补全只显示已经进入公开目录的歌曲。

### 拿到唱片但听不到

确认客户端接受了服务器资源包、距离唱片机不超过 25 格，并尝试执行 `/music pack` 重新加载资源包。
